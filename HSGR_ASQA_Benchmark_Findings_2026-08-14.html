Evidence-first benchmark report

HSGR × ASQA从“候选值坍缩”转向“长答案候选节点”后的第一轮证据

ASQA 解决了旧数学任务中“候选值几乎都相同”的基本盘问题：一个问题天然包含多个语义不同的答案 facet。实验进一步证明，给出正确 facet 节点会显著提高完整回答率；但目前的 answer-prefix hidden state 不能可靠判断哪个未覆盖节点最终会漏掉。因此，benchmark 和静态结构方向可保留，当前 hidden Guide 目标必须停止。

为什么 ASQA 比旧数学设定更合适

这里的“节点”是答案需要覆盖的语义方面，不是重复采样得到的数值。

旧设定

数学候选值

同一中间节点反复采样后，经归一化常落到同一个数值。候选域缺少变化，Guide 没有什么可选。

新设定

ASQA 候选节点

一个模糊问题含 2–6 个 disambiguated facets，例如不同人物、年代或条件下的答案。节点之间保持语义身份。

固定约束

Fixed support

所有方法使用同一组 ALCE oracle top-5 passages，不允许重新检索、重排或根据结果修补证据。

核心变化：我们没有把 candidate domain 改成完整路径，也没有做 Tree-of-Thought。候选单位从“节点里的多个值”改成“长答案必须覆盖的多个语义节点”。

关键失败：full hidden 比 surface-only 低 0.071 AUROC；Recall@1 只提高 0.048，低于预设的 +0.10 gate。

为什么会失败

  • 可决策状态太少：held-out 只有 42 个 mixed states 同时含“以后会补上”和“最终仍遗漏”的节点，低于最低 60。
  • 目标偏斜：保留节点中 66.86% 最终仍遗漏，高于冻结上限 60%。
  • 前缀交互弱：node-only 与 surface control 接近，而加入 prefix hidden 后反而变差。
  • 稳定性不够：full reader 在两个固定 halves 的 AUROC 都输给 surface；Recall 也只在一半中提高。
更准确的解释

hidden/node 表征中可能包含“这个 facet 本身难不难”的信息，但没有证据表明它编码了足够强的当前回答状态 × 具体节点交互，从而提前判断自然续写会漏掉谁。

不能这样解释

不能因为 wrong-node control 的 Recall@1 有下降，就宣称 hidden Guide 已有效。它的 AUROC 仅下降 0.023，并且绝对表现、surface 增益、两半稳定性和 apparatus gates 均失败。

停止规则

按冻结协议，本目标失败后不运行 causal activation steering。继续调层、调阈值或只挑 75% prefix 都属于基于结果追调，不能作为可靠证据。

正面含义：all-node scaffold 修复了 37 个 direct 失败样本；direct / all-node 组合上限比 direct 高 19.27 个百分点，说明结构干预存在真实空间。
负面含义：all-node 同时破坏了 10 个 direct 成功样本。全量加节点不是单调有益，因此需要“何时、用哪个节点”的更细机制。
尚未得到真正的 per-node Oracle：P1x 一次展示全部节点，没有分别注入每个 facet。因此我们还不知道单节点干预能否超过 all-node scaffold、不同题的最佳节点是否足够多样、以及 selector 是否有实际发挥空间。
6

现在能与不能声称什么

对 proposal 最重要的是把 benchmark property、oracle apparatus 与最终方法贡献分开。

已支持

ASQA clean subset 提供非坍缩 candidate-node domain。节点是语义不同的 facets；正确节点身份对长答案完整性有显著、配对的因果影响。

部分支持

HSGR 可以在这个 benchmark 上继续探索。成立的只是“结构有用”的必要条件；hidden selector 和因果 Guide 尚未成立。

不支持

当前 answer-prefix hidden state 能识别最终遗漏节点。full reader 不但未过 gate，还落后于 surface-only。

不支持

57.81% 或 63.02% 是 HSGR 当前准确率。前者依赖 gold nodes，后者还依赖事后选结果；只能报告为 oracle ceiling / actionability diagnostic。

尚未验证

单个节点具有可选择、互补的因果效用。需要 fresh single-node intervention 实验后才能决定是否值得设计新的 latent selector。

7

对 HSGR 技术路线的影响

保留最强证据，同时严格避开 current methods 的重合。

保留的骨架

Candidate-node composition

  • 固定 passages，不把 retrieval / reranking 当贡献。
  • 候选域是短语义节点，不是完整路径或 partial trajectory。
  • 目标是长答案的多 facet coverage，不再制造错误数值来增加候选多样性。
  • Guide 最终必须体现 node-specific latent conditioning，而不是只在 prompt 中追加一句话。
排除的实现

不能作为论文主方法

  • 继续优化已失败的 future-omission prefix classifier。
  • 把 gold facet question 的 prompt routing 包装成 hidden Guide。
  • 枚举完整回答路径、树搜索或 ToT/DPTS 式 trajectory selection。
  • 把 gold labels、short-answer aliases 或最终答案泄漏到特征中。
论文边界：文本节点注入可以继续用作 oracle apparatus，帮助判断“有没有可修复空间”；但最终贡献必须在不展示 gold node 文本的前提下，由 hidden/latent mechanism 产生可归因的覆盖增益，并与 surface、wrong-node、random-node、text-only 等控制比较。
8

下一步最有信息量的验证

不是马上训练另一个 hidden probe，而是先确认单节点选择问题本身是否值得解决。

P0

Fresh single-node intervention Oracle

在 427 个 clean cases 中使用未进入当前 192 样本的 fresh subset。对每个 facet 单独做一次文本干预，同时保留 direct 与 all-node。提前冻结样本、prompt、解码和 gates。

P1

判断 selector 是否有必要

比较 direct、all-node、随机单节点、最佳固定位置、KEEP-or-single-node Oracle。重点看：单节点 Oracle 是否明显超过 all-node/KEEP，以及最佳节点是否在题目间足够多样，而不是总由同一位置支配。

P2

Oracle 通过后，重新定义 hidden target

标签应来自“注入该节点带来的边际覆盖收益”，而不是“自然续写最终会不会遗漏”。这会直接对齐 Guide 的因果价值；但 prompt intervention 仍只用于构造/审计标签，不是最终方法。

STOP

明确停止条件

如果 single-node Oracle 不超过 all-node/KEEP，或最佳节点几乎不具多样性，就停止 node selection 主线：结构有用，但无需可学习 selector。不要再靠换层、换阈值或筛子集挽救。

客观风险：即使 single-node Oracle 通过，如何在没有 gold disambiguated questions 的真实推理场景中构造候选节点仍是单独难题。当前 ASQA 只能先证明机制，不能直接证明部署可行性。

指标与术语

Facet：ASQA 发布的一个 disambiguated QA pair。STR-EM：每题已覆盖 facet 比例的平均值。STR-HIT：全部 facet 均出现在长答案中的题目比例。

Facet alias 使用 ALCE normalization：小写、去 ASCII 标点和冠词 a/an/the、归一化空格，再做 alias substring matching。短答案只用于评分与标签，从未出现在 P1x true-facet prompt 的 checklist 答案中，也未进入 P2x 的模型特征。

报告口径：截至 2026-08-14 已完成并冻结的 ASQA P0 / P1x / P2x 结果。结论按“已验证事实—合理解释—开放问题”分层；任何 Oracle 数字都不等同于可部署 HSGR 效果。
